
# Exercise 0.6: New note in Single-page app

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note over browser: User writes a note and clicks Save

    Note over browser: JavaScript prevents normal form submission
    Note over browser: JavaScript creates a note object

    browser->>server: POST /exampleapp/new_note_spa (JSON)
    activate server
    Note over server: Server saves the note
    server-->>browser: HTTP 201 Created
    deactivate server

    Note over browser: JavaScript processes the response
    Note over browser: JavaScript updates the notes list
    Note over browser: New note appears without page reload
```
